\section{Teknologi yang Digunakan}

Selama pelaksanaan magang, berbagai teknologi digunakan untuk mendukung proses
pengembangan perangkat lunak, kolaborasi tim, serta aktivitas operasional
sehari-hari. Teknologi-teknologi tersebut dapat dikelompokkan sebagai berikut:

\begin{enumerate}
      \item \textbf{Framework dan bahasa pemrograman}

            \begin{enumerate}[noitemsep, topsep=0pt]
                  \item \textbf{Flutter (Dart)}

                        Digunakan pada periode awal magang (Januari--Februari 2026) untuk pengembangan
                        dan pemeliharaan aplikasi \textit{mobile} \textit{HealthyOne} dan
                        \textit{Canvasser} menggunakan pendekatan \textit{Server-Driven UI} (SDUI) dan
                        struktur \textit{Model-View-Controller} (MVC).

                  \item \textbf{React (Next.js dan TypeScript)}

                        Digunakan mulai pertengahan Februari 2026 untuk pengembangan ulang antarmuka
                        \textit{HealthyOne} dan \textit{Canvasser}. Teknologi ini secara bertahap
                        menggantikan Flutter sebagai \textit{tech stack} \textit{front-end} utama yang
                        digunakan perusahaan.

                  \item \textbf{Toraja (Django/Python)}

                        Framework \textit{back-end} internal yang mulai digunakan sejak pertengahan
                        April 2026 untuk pembuatan dan penyesuaian \textit{endpoint} API yang
                        menghubungkan layar React dengan database, seiring dengan perubahan peran dari
                        \textit{Front-End Developer} menjadi \textit{Full-Stack Developer}.
            \end{enumerate}

      \item \textbf{Library dan \textit{tool} pendukung}

            Pada pengembangan aplikasi berbasis React, digunakan beberapa \textit{library}
            dan \textit{tool} pendukung, antara lain Mantine UI dan Tailwind CSS untuk
            kebutuhan \textit{styling} dan komponen UI, serta AG Grid sebagai dasar
            implementasi komponen DataView yang menggantikan komponen \textit{ListBased}.
            Selain itu, digunakan pula lapisan \textit{services}, \textit{hooks},
            \textit{mapper}, \textit{helper}, dan \textit{utils} untuk mendukung
            pengelolaan \textit{state} dan komunikasi API dengan Toraja.

      \item \textbf{Perangkat kolaborasi dan produktivitas}

            Untuk mendukung koordinasi tim dan pengelolaan pekerjaan, perusahaan
            menggunakan OpenProject sebagai sarana manajemen \textit{task} dan pencatatan
            KPI, GitLab untuk \textit{version control} dan proses \textit{merge request},
            Sistem Informasi Pelaporan Perusahaan (SIPP) Pharos untuk kebutuhan presensi
            dan administrasi karyawan, serta WhatsApp sebagai media komunikasi sehari-hari
            antar anggota tim.
\end{enumerate}
